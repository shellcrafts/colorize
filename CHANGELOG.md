# Changelog

## [1.1.0] - 2026-03-18

### Added
- Gradient color support (`gradient()`)
- Background color support (`bg()`)
- TypeScript type definitions

### Changed
- Improved gradient ratio calculation for single character strings

## [1.0.0] - 2025-12-10

### Added
- Initial release
- Named ANSI color support (`colorize()`)
- Text style support (`style()`)
- Hex true color support (`hex()`)
- ANSI stripping utility (`strip()`)
